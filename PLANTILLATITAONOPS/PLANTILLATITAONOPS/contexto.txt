2. Infraestructura de Base de Datos (Supabase Cloud)
Motor: PostgreSQL alojado en Supabase (Región AWS US East 1).

Mecanismo de Conexión: Se implementó obligatoriamente el Session Pooler (IPv4). La conexión directa de Supabase requiere IPv6 nativo y falla en redes locales convencionales, por lo que el Session Pooler en el puerto 5432 es el estándar activo.

Clase Singleton: com.titanops.conexion.ConexionBD.
Para obtener una conexión activa en cualquier DAO o consulta:
Connection con = ConexionBD.getInstancia().getConexion();

Maneja reconexión automática si el canal se cierra y previene la apertura descontrolada de sockets.

    4. Contrato Genérico DAO (com.titanops.dao.CrudDAO<T>)
Todas las operaciones CRUD estándar deben implementar la interfaz genérica CrudDAO<T>:


package com.titanops.dao;

import java.util.List;

public interface CrudDAO<T> {
    boolean insertar(T entidad);
    boolean actualizar(T entidad);
    boolean eliminar(int id);
    T obtenerPorId(int id);
    List<T> listarTodos();
}





Regla de diseño: Las mutaciones (insertar, actualizar, eliminar) devuelven boolean para reportar de inmediato el éxito/fallo a la interfaz Swing.


Consultas especializadas (búsquedas por DUI, login con credenciales, filtrado por estado) se declaran como métodos adicionales en sus respectivos DAOs específicos.
